FITTRACK + CARETRACK — foundation release
Back up CareTrack from Settings before updating. Keep the existing GitHub Pages URL and repository; replace files at root and upload the fitness folder. Do not delete existing app data. Open CareTrack first, then Open FitTrack AI Pro. For Windows testing run py -m http.server 8000 in this folder and open http://localhost:8000. For iPhone open the existing HTTPS site in Safari. FitTrack is at fitness/ and can be added to Home Screen. Separate installed iOS PWAs may isolate storage: use CareTrack backup export and FitTrack More > import CareTrack backup, or use both pages within the same installed CareTrack app. Import again after rota changes if isolated. No cloud data sharing. Existing CareTrack source retained except navigation and service worker cache. Fitness profile values are illustrative defaults; edit before using targets. Calendar reminders export ICS; import and verify in Calendar. Scriptable: create a script, paste fitness/Motivation-Scriptable.js, save, add Scriptable widget and select script. iOS controls refresh timing. No native Apple Health, watch, camera OCR, food recognition, voice, social, actual AI, full meal generator, exercise images, advanced recovery analytics or automatic push yet. Rule-based foundation only. JS syntax checked; no physical iPhone test. Backups contain private data; keep local.
