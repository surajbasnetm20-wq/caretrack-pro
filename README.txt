CARETRACK PRO — personal PWA
Extract ZIP. Windows: install Python 3 if needed, open PowerShell in extracted folder, run py -m http.server 8000 and open http://localhost:8000. For iPhone use HTTPS hosting: create a free public GitHub repository, upload the contents (not the enclosing folder), Settings > Pages > Deploy from a branch > main / root > Save. Open the published HTTPS URL in Safari, Share > Add to Home Screen. Open once online before offline use. No personal records are uploaded by the app; source is public. Backups are unencrypted JSON; keep them private. Browser storage can be erased, export backups regularly. Use Calendar reminder export and import into Apple Calendar; verify alerts there. PDF via browser print (Windows or iOS print/share workflow). Payroll is a non-cumulative monthly estimate, not exact PAYE; pension treated as after-tax deduction, NI category A, England/Wales/NI. Pay period assigned by shift start and cutoff; payday is informational. Rates entered per shift; no automatic holiday premium. Annual leave is manual calendar-year entitlement. Work-life alert is a recent-hours heuristic. No AI, cloud, native push, automatic bank holiday feed or native app store release. Source syntax checked, not tested on physical iPhone. 

V3: Tap any calendar date to open saved shifts immediately. Multi-select remains optional. Back up before updating.
